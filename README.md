🎂 BruniBolo

Bem-vindo(a) ao BruniBolo! 🧁✨

Um projeto acadêmico que une tecnologia e criatividade para desenvolver uma experiência digital no universo da confeitaria. O projeto envolve documentação, modelagem UML e prototipação de interfaces, aplicando conceitos de Programação 1 e Engenharia de Software.
